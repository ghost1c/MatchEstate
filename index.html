About MatchEstate

MatchEstate is an AI-powered Google Workspace Add-on developed for real estate professionals. The application helps agents compare customer requirements with property portfolios stored in Google Sheets. Using Google's Gemini AI, MatchEstate analyzes customer preferences, calculates compatibility scores, ranks matching properties, and generates professional AI-assisted reports. The application is designed to improve property matching efficiency while keeping users in their existing Google Workspace environment.

Main Features

AI Property Matching

Analyze customer requirements and compare them with your real estate portfolio using Gemini AI.

Google Sheets Integration

Manage your property portfolio directly inside Google Sheets.

Professional Reports

Generate AI-assisted property matching reports for customers.

Google Drive Support

Save generated reports directly into your own Google Drive.

How MatchEstate Works

1. Property Portfolio

Store your property listings in Google Sheets.

2. Customer Requirements

Enter your customer's property requirements.

3. AI Analysis

Gemini AI evaluates compatibility between customer requirements and your portfolio.

4. Ranked Results

Receive ranked property recommendations with AI explanations.

Why MatchEstate Requests Google Permissions

  • Access Google Sheets selected by the user to read property portfolio data.
  • Create AI-generated reports based on customer requirements.
  • Save generated reports into the user's own Google Drive.
  • Authenticate users securely using Google OAuth.
  • Never access files without explicit user permission.
  • MatchEstate never sells user data or accesses unrelated Google content.

Privacy & Security

MatchEstate follows Google's OAuth policies and Google API Services User Data Policy. Only the minimum permissions required for the application's functionality are requested. All user data remains under the user's Google account and is processed only to provide the requested matching service.
