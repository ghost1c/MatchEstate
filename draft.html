Draft Tester Opt-Out

Information for users participating in the MatchEstate draft testing program.

Overview

This page explains how participants can leave the MatchEstate draft testing program. If you no longer wish to receive access to pre-release versions of MatchEstate, you may request removal at any time.

How to Leave the Program

To opt out of the MatchEstate draft testing program, please contact our support team using the email address below. Please include the Google Account that you used to join the testing program so we can process your request more efficiently.

Support

If you need assistance regarding the draft testing program, please contact us.

Email: tahsinaktasbjk@gmail.com

We typically respond within 24–48 business hours.

What Happens After Opting Out?

After your request has been processed, your Google Account will be removed from the MatchEstate draft testing program. You will no longer receive access to pre-release or preview versions of MatchEstate. This does not affect your ability to install or use future public versions released through Google Workspace Marketplace.

Need Help?

If you have questions about the draft testing program, installation, or MatchEstate in general, please visit our Support Center.
