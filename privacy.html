Privacy Policy

Last updated: July 2026

Introduction

MatchEstate is an AI-powered Google Sheets add-on designed to help real estate professionals compare customer requirements with property portfolios. This Privacy Policy explains how information is collected, used, and protected.

Information We Collect

MatchEstate processes only the information required to provide its matching functionality, including spreadsheet data selected by the user and configuration settings such as the user's Gemini API key.

Google Workspace Permissions

The add-on accesses Google Sheets only after explicit user authorization. Access is limited to the permissions granted by the user through Google's OAuth consent process.

Gemini API Key

Users provide their own Gemini API key. The key is stored using Google Apps Script user properties for the authorized user and is used only to communicate with the Gemini API on the user's behalf.

How We Use Information

Information is used solely to analyze property portfolios, generate AI-powered matching results, and provide requested functionality. MatchEstate does not sell personal information or use customer data for advertising.

Third-Party Services

MatchEstate may communicate with Google services and user-configured AI services such as Gemini to perform requested operations. These services are governed by their own privacy policies.

Data Security

We take reasonable technical and organizational measures to protect user information. However, no internet transmission or storage system can be guaranteed to be completely secure.
