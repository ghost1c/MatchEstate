Privacy Policy

Last Updated: August 6, 2026

Introduction

MatchEstate is an AI-powered Google Workspace Add-on designed for real estate professionals. This Privacy Policy explains what information is processed, how it is used, and how it is protected when using MatchEstate.

Information We Process

MatchEstate processes only the information required to provide its functionality. This may include:

  • Property portfolio information stored in Google Sheets.
  • Customer requirements entered by the user.
  • Google Drive files created by MatchEstate.
  • User preferences required for application configuration.
  • A user-provided Google Gemini API Key.

MatchEstate does not collect sensitive personal information beyond what users voluntarily provide.

Google Workspace Permissions

MatchEstate requests only the minimum Google permissions required to provide its services. Access to Google Sheets and Google Drive is granted only after explicit user authorization through Google's OAuth consent process. The application accesses only the files that the user has selected or explicitly authorized. Google user data is accessed solely to provide the functionality requested by the user.

Google API Services User Data

MatchEstate does not sell Google user data, use it for advertising, or transfer it to third parties except when necessary to communicate with Google Workspace services or Google's Gemini API. MatchEstate never uses Google Workspace API data to develop, improve, or train generalized artificial intelligence or machine learning models.

Google Gemini API Key

Users provide their own Google Gemini API Key. The API key is stored securely using Google Apps Script User Properties and is used only to communicate with Google's Gemini API on behalf of the user. The API key is never shared with third parties.

How Information Is Used

Information processed by MatchEstate is used exclusively to:

  • Compare customer requirements with property portfolios.
  • Generate AI-powered compatibility analyses.
  • Create property matching reports.
  • Save reports to Google Drive when requested by the user.
  • Provide the features explicitly requested by the user.

MatchEstate never uses user information for advertising, marketing, profiling, or analytics.

Third-Party Services

MatchEstate communicates only with Google Workspace services and Google's Gemini API to perform operations explicitly requested by the user. These services are governed by their own privacy policies. No information is shared with third parties for advertising, profiling, analytics, or marketing purposes.

Data Retention

MatchEstate stores only the minimum information necessary for application functionality. Users may remove stored settings by uninstalling the add-on or clearing their application settings. Users may also revoke MatchEstate's access to their Google Account at any time through Google's Security Settings.

Data Security

Reasonable technical and organizational safeguards are used to protect user information. Although no method of electronic storage or transmission is completely secure, MatchEstate follows industry best practices to help protect user data.

Google API Services User Data Policy

MatchEstate's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes to this Privacy Policy

This Privacy Policy may be updated periodically. Any changes will be published on this page together with the updated revision date.
