Frequently Asked Questions

How do I install MatchEstate?

Open Google Sheets, then go to Extensions → MatchEstate.

How do I start using AI Matching?

Complete the First Setup process, enter your Gemini API key, and start AI Property Matching.

Where can I get a Gemini API Key?

You can create your API key through Google AI Studio.

My matching process failed. What should I do?

Verify that your API key is valid and that your internet connection is available. If the issue continues, please visit the Support page.

Where can I report a bug?

Please submit bug reports through the MatchEstate GitHub Issues page.
