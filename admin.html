Workspace Administrator Guide

Information for Google Workspace administrators

Overview

MatchEstate is an AI-powered Google Workspace Add-on designed for real estate professionals. The application helps users compare customer requirements with property portfolios stored in Google Sheets by using Google's Gemini AI.

Administrator Configuration

MatchEstate does not require domain-wide installation, administrator privileges, or special Workspace configuration. Each user authorizes the application individually using their own Google Account.

User Setup

Each user completes a simple one-time setup after installing MatchEstate.

  • Authorize MatchEstate with Google OAuth.
  • Open MatchEstate from Google Sheets.
  • Enter a personal Google Gemini API Key.
  • Start AI-powered property matching.

Permissions

MatchEstate requests only the minimum Google Workspace permissions required to provide its functionality. The application accesses only the Google Sheets and Google Drive files that the user explicitly authorizes. No administrator approval is required unless your organization restricts third-party Google Workspace applications.

Privacy & Security

Each user's data remains private within their own Google Account. MatchEstate does not require administrator privileges and does not access organizational data beyond the permissions explicitly granted by the individual user. Google Workspace data is processed only to provide the functionality requested by the user.

Administrator Notes

Organizations that restrict third-party Google Workspace applications may require administrator approval before users can install MatchEstate. For organizations without these restrictions, users can install and authorize MatchEstate individually without additional administrator configuration.
