Workspace Administrator Guide

Information for Google Workspace administrators

Overview

MatchEstate is an AI-powered Google Workspace Add-on designed for real estate professionals. The application allows users to compare customer requirements with property portfolios stored in Google Sheets using Google's Gemini AI.

Administrator Configuration

MatchEstate does not require any domain-wide installation or special administrator configuration. Each user authorizes the application individually using their own Google Account.

User Configuration

After installation, every user completes a simple one-time setup.

  • Authorize the application with Google OAuth.
  • Open MatchEstate inside Google Sheets.
  • Enter a personal Google Gemini API Key.
  • Begin using AI-powered property matching.

Permissions

MatchEstate requests only the Google permissions required to provide its functionality. The application accesses Google Sheets and Google Drive only after explicit user authorization. No administrator approval is required unless your organization restricts third-party Google Workspace applications.

Security

Each user's data remains private within their own Google Account. MatchEstate does not require administrator privileges and does not access organizational data beyond the permissions granted by the individual user.
